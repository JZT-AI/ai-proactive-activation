当前项目已精简为静态预览版本，仅保留页面展示相关内容。

- `share.html`：最终可直接预览的页面
- `share.tsx`：与页面内嵌代码同步的源码
- `README.md`：使用说明
- `.gitignore`：仓库忽略规则

## 本地预览

在当前目录执行：

```bash
python3 -m http.server 8002
```

浏览器打开：

`http://localhost:8002/share.html`
