# AI私域助手 · 消息通知原型

[在线体验](https://jzt-ai.github.io/ai-proactive-activation/message-notifications/)

包含自动化通知管理、小B人群圈选、共用人群包/用户详情和多渠道触达。所有数据、权限、播报模板及任务结果均为演示，不发送真实消息。

## 演示入口

- 自动化任务：助手标题栏流程节点图标（Workflow）；当前任务分类为“消息通知”，以分组标题展示；列表展示任务名称、触达渠道、通知类型和状态，无详情入口。普通成员查看，管理员调整当前城市通知开关；关闭后由对应业务系统停止该规则的后续消息触达，原型仅模拟状态。
- 小B圈选与触达：确认条件后查看人群预览，输入“确认”或点击按钮使用当前名称建包；重复确认不重复创建，点击配置卡继续。
- 多渠道配置：四渠道独立勾选并用单列表单填写，无右侧效果预览；完整内容在任务确认卡核对。Push/站内信固定有客App，服务号固定365淘房服务号，无其他发送对象选项；各渠道文案独立，通知类型共用。
- App Push支持播报开关和预置提示选择；任务确认后只允许手改名称，发送安排通过自然语言调整。
- 任务城市按账号权限选择（可模拟全国权限）；全国暂无企微私聊通道，不可新增选择/编辑或提交。切换全国后已选企微保留草稿，需主动取消或改选具体城市；不依赖人群包城市属性。
- 用户详情展示角色、付费及主营/副营交易类型等信息。
- 原型折叠工具可模拟城市权限、创建失败和结果待确认。

## 文件

- `index.html`：分享入口，自动打开助手。
- `share.html`：可运行页面，内嵌TSX源码。
- `share.tsx`：维护源码，与页面内嵌内容保持同步。
- `触达框架.css`：界面样式。

页面通过React、Babel和图标/样式CDN加载依赖。演示状态保存在访问者自己的浏览器localStorage中，不连接业务系统。GitHub Pages从仓库main分支发布此目录。
