# AI私域助手原型

[在线体验](https://jzt-ai.github.io/ai-proactive-activation/message-notifications/) · [GitHub源文件](https://github.com/JZT-AI/ai-proactive-activation/tree/main/message-notifications)

本地演示自动化任务管理、站内信管理、小B人群圈选和小B通知。数据、身份、权限及任务结果均为模拟，不发送真实消息。

站内信和其他渠道均由推送系统创建任务。站内信使用「应用内发送」渠道；原型仅演示任务创建和返回结果，不发送真实消息。

## 文档与文件

- [自动化任务PRD](../../AI私域助手自动化任务-PRD.md)：注册任务列表与按钮权限与全站启停。
- [有客App消息管理PRD](../../有客App消息管理-PRD.md)：站内信管理的查看、屏蔽和恢复显示。
- [小B圈选与通知PRD](../../小B圈选与通知-PRD.md)：圈选、配置、确认、任务创建与异常。
- `share.tsx`为唯一维护源码，与`share.html`的`app-source`同步；样式位于`触达框架.css`。
- `08-过程与历史`保存调整前备份及走查截图。历史截图不替代当前PRD。

## 演示路径

### 自动化任务

从助手流程节点图标（Workflow）进入，与历史对话图标区分。列表上方以“消息通知”分组标题展示本期任务分类；只展示实际接入的分类，后续接入第二类时使用横向标签切换，扩展规则由PRD维护。业务系统注册已有触达规则的名称、任务分类和渠道；列表展示名称、渠道及状态，不提供任务详情、通知时点或操作记录入口。用户可查看全站状态。有按钮权限的角色可启停。关闭后，对应业务系统在全站停止该规则的后续触达，状态以业务实际生效结果为准。原型仅模拟状态，不操作线上业务规则。

页尾工具可独立模拟启停按钮权限与工作城市。14 项任务各自共享一个全站状态。

在「消息通知」标题右侧进入「站内信管理」。列表仅展示运营主动发送的站内信批次。西安示例包含两次同标题发送，可对比单次屏蔽与恢复。使用管理员身份走查操作，普通成员可查看列表和正文。

### 小B圈选与通知

1. 圈选模式使用「人群圈选」。确认条件和预览后建包；成功时回复「人群包创建完成。」并提供详情入口。
2. 建包后，切换执行模式，选择「小B通知」并引用人群包，或说「给 @本周名单 里的经纪人发个通知」。各站点及全国视图均可调用。任务城市仅西安可选。可通过「自动化任务 → 原型演示工具」切换当前城市和任务城市权限。
3. 任务城市下拉展示账号有权限的城市。本期仅西安可选，其他权限城市标记「暂未开放」。可选择 App Push、站内信、企微私聊和服务号模板消息通知中的一个或多个渠道。企微只读展示西安 B 端客服和西安通道，Push 和站内信固定发送至有客App，服务号固定为365淘房服务号。
4. 免打扰默认开启，所有所选渠道共用每日 22:00 至次日 08:00 的固定时段。关闭时不配置时段。
5. 通知配置完成前停用会话输入；关闭弹窗保留草稿。进入任务确认后恢复输入。新一轮配置为空。确认后锁定城市、免打扰、客服、渠道和内容。任务确认弹窗预填按人群包和消息内容生成的示例名称，可手动修改。返回会话可用自然语言修改发送时间。
6. 勾选几个渠道就创建几条推送任务，所选渠道决定各条任务的通道。结果卡展示创建结果和原因，成功任务独立返回ID，列表按渠道区分同名任务。

- 站内信配置标题、正文和选填图片。跳转方式为不跳转、365获客宝小程序、有客App。App Push 使用相同跳转选项。选择有客App后手填页面路径，例如 /pages/mine/mine。
- 企微私聊支持正文、图片、链接卡片和获客宝小程序卡片，按此顺序每段间隔 2 秒。
- 服务号使用「服务进度提醒」。跳转目标可选365获客宝小程序或 H5 链接。唤起有客App指定页时填写对应的有客 H5 中转链接。[中转页演示](https://jzt-ai.github.io/ai-proactive-activation/message-notifications/youke-h5.html?target=wallet)

人群圈选复用原有技能。助手回显业务筛选条件，条件缺失时请运营补充具体描述。小B抽样在共享用户详情展示付费有客币可用余额、赠送有客币可用余额、最近赠送币到期时间、角色ID、入驻城市、主营区属、主营板块。可输入「圈选付费有客币可用余额等于 0 的小B」或「圈选未来 7 天内有赠送币到期的小B」走查。原型使用模拟数据。

每个成功任务沿原四段详情展示自己的渠道和快照，不新增总任务。原有C端主动激活、资源和群聊流程保留在本副本内，基线`../AI私域助手主动激活内容生成`不受影响。

## 运行与验证范围

在项目根目录运行：

```bash
python3 -m http.server 8016 --bind 127.0.0.1
```

访问`http://127.0.0.1:8016/原型/AI私域助手消息通知/index.html`。也可直接打开`share.html`；需要联网加载React、Babel、图标及样式依赖。

历史资源及自动化状态保存在当前来源的localStorage，HTTP与文件来源各自独立。对话使用内存状态；切换自动化工作区保留对话，刷新页面不恢复对话。

各渠道的模拟任务均保存 `pushConfigSnapshot`，站内信按「应用内发送」渠道保存，演示任务ID统一为 `DEMO-T-*`。这些本地字段仅用于走查，不是生产接口合同。

原型只覆盖有限自然语言和模拟结果，不代替新报表、真实鉴权、账号/模板、推送去重及结果查询验收。当前规则与未决项以PRD为准。

角色与系统横向分列、流程自上而下，左侧标注阶段：[泳道图查看器](消息通知-角色与系统业务流程.html) · [可编辑draw.io源图](消息通知-角色与系统业务流程.drawio)。

在「资料 → 推送任务」可查看状态。「推送中」任务可确认中止，中止后状态为「已中止」。原型使用模拟推送状态。

免打扰默认22:00至次日08:00，可修改起止时间，所选渠道共用。
