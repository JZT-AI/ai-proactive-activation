# AI私域助手 · 消息通知原型

[在线体验](https://jzt-ai.github.io/ai-proactive-activation/message-notifications/)

包含自动化通知管理、小B人群圈选、共用人群包/用户详情和「通知小B」技能。所有数据、权限、播报模板及任务结果均为演示，不发送真实消息。

## 演示入口

- 自动化任务：助手标题栏流程节点图标（Workflow）；当前任务分类为“消息通知”，以分组标题展示；列表展示任务名称、触达渠道、通知类型和状态，无详情入口。普通成员查看，管理员调整当前城市通知开关；关闭后由对应业务系统停止该规则的后续消息触达，原型仅模拟状态。
- 小B圈选与触达：先确认圈选并建包，随后切换执行模式。选择「通知小B」并引用人群包，或 @人群包并用经纪人、分销中介、中介、小B 表达发通知需求。无需先给渠道和内容。建包完成后仅提示成功并提供详情入口。
- 渠道配置：可选择一个或多个渠道。App Push、站内信、企微私聊和服务号各用独立表单。Push/站内信只读展示有客App，服务号只读展示365淘房服务号；企微只读展示B端客服及任务城市对应通道。支持正文、图片和链接卡片，按此顺序每段间隔 2 秒。服务号固定用「服务进度提醒」发送通知，跳转目标为365获客宝小程序。App Push 和站内信暂不开放跳转配置。
- App Push、站内信、企微和服务号统一返回推送任务ID，创建成功的任务逐条进入会话任务列表和资源。
- 触达配置卡出现后停用会话输入；关闭弹窗保留草稿，确认配置后恢复输入。
- App Push支持播报开关和预置提示选择；任务确认后只允许手改名称，发送安排通过自然语言调整。
- 任务城市沿用推送系统选项，含全国，并按账号权限展示。全国不可新增、编辑或提交企微；切换全国后保留已选企微草稿，需取消企微或切回具体城市。
- 用户详情展示角色、付费及主营/副营交易类型等信息。
- 原型折叠工具可模拟城市权限、创建失败和结果待确认。

## 文件

- `index.html`：分享入口，自动打开助手。
- `share.html`：可运行页面，内嵌TSX源码。
- `share.tsx`：维护源码，与页面内嵌内容保持同步。
- `触达框架.css`：界面样式。

页面通过React、Babel和图标/样式CDN加载依赖。演示状态保存在访问者自己的浏览器localStorage中，不连接业务系统。GitHub Pages从仓库main分支发布此目录。

[角色与系统泳道图](消息通知-角色与系统业务流程.html)：角色与系统横向分列，流程自上而下、左侧标注阶段，顶部以颜色区分角色；包含圈选建包、多渠道触达及自动化任务启停；支持适合宽度/原始大小切换与draw.io源图下载。
